# LYDH: Look where humans don't. 

Built for the Databricks × Hack-Nation *Agentic Scientific Discovery* challenge. Orchestrated by Omnigent; agents powered by Claude.

---

## The bottleneck we attack

Science is limited by human attention. A researcher only tests the explanations their training, field and experience exposed them to. Everything outside that never gets examined.

- In 1986, Don Swanson showed that two medical literatures (fish oil and Raynaud's syndrome) never cited each other, yet together suggested a treatment nobody had proposed; a clinical trial supported it three years later [3].
- As fields grow, attention concentrates on what is already famous: across 1.8 billion citations among 90 million papers, large fields tend to ossify around their canon [4].
- And much of what we do examine does not repeat: in Nature's survey of 1,576 researchers, more than 70% had failed to reproduce another scientist's experiment, and more than half their own [1]. In psychology, 97% of original studies were significant versus 36% of replications [2]. Amgen confirmed 6 of 53 landmark cancer studies [5].

Large language models have read across more disciplines than any person can. They may propose bridges our biology would not. But a creative idea without proof is just a guess. LYDH pairs broad proposal with ruthless falsification.

## What makes LYDH different 

| Existing direction | What it does | What LYDH adds |
|---|---|---|
| AI-Newton [6] | Extracts concepts and laws from many experiments | We do not build laws. We find hidden causes behind an anomaly and choose where to look next. |
| MIT/Harvard world-model test [7] | Shows accurate prediction is not understanding | We ask the next question: when the model is missing something, can it notice, propose what, and design the measurement that would prove it wrong? |
| Typical agent pipelines | Chain prompts | The LLM proposes, code calculates, the simulator judges, statistics verify. |

The loop: anomaly → competing hypotheses → the measurement where they disagree most → falsify → replicate on held-out data.

## What we measured (and what we did not)

Testbed: a simulated solar system with a hidden planet. We use it because the real answer is known, so the lab can be graded. The loop itself is domain-agnostic: swap the simulator, keep the agents.

Result: 4 scenarios × 100 repeats × 3 policies = 1,200 runs

| Policy | Mean measurements | Found the cause | Replicated on held-out data |
|---|---|---|---|
| Random | 4.80 | 83% | 84% |
| Biggest error (greedy) | 3.87 | 88% | 89% |
| LYDH | 3.61 | 90% | 91% |

- LYDH used 1.33× fewer measurements than random (95% CI 1.25–1.41), about 25% fewer.
- Per scenario (random / LYDH): 1.02×, 1.17×, 1.32×, 1.67× in the hardest case, about 40% fewer.
- Against the stronger greedy baseline the gain is smaller: 1.07× (CI 1.01–1.14). We report it because it is the honest number.
- Median measurements were 3 for all policies. The advantage is in the average and the hard cases, not the easy ones (scenario 0 shows almost no gain).
- All policies share the same math and the same stopping rule. Only the choice of the next measurement changes.

What we did not do: discover a real planet; use real data; show cross-disciplinary idea generation. Today the hypothesis bank is generated by code; agents register and explain it. Bridging ideas across fields is the next step, not a result.

Raw outputs: `runs/benchmark.csv`, `runs/benchmark_summary.json`, `runs/benchmark.png`.

## How it works

```
Scout → Observer → Hypothesis → Falsifier/Planner → Scientist/Replicator
              (Omnigent hands off structured JSON; every step goes into a research record)
```

- Physics: gravity simulated numerically with SciPy (`solve_ivp`), in `orbital_env.py`.
- Inference (`engine.py`, no LLM):** a Bayesian engine tracks 26 competing hypotheses (no hidden body, plus 25 hidden bodies across 5 masses × 5 orbits). Chi-squared tests flag anomalies; a hypothesis below p = 0.001 is falsified.
- Planner: simulates every surviving hypothesis forward and measures on the date where predictions diverge most.
- Replication gate: a conclusion needs at least 3 measurements and must hold on held-out data with at least 100:1 evidence over the no-hidden-body model.
- Orchestration: Omnigent coordinates five specialist agents (`attn_lab/attn_lab.yaml`), running Claude through the `claude-sdk` harness.
- UI: Streamlit app with a replay of a real saved run.

## Agent policies and controls

- The agents never see the answer key.** The ground truth is read only inside `finalize()` (`attn_session.py`) to grade the result.
- LLM proposes, code calculates, simulator judges.** Agents cannot invent numbers; they quote tool outputs.
- Every hypothesis is labeled as AI-generated.**
- Research record: hypothesis, evidence, chosen measurement, reason, result, belief change, next decision and replication status are saved as JSON in `runs/`.
- Fallback: the local engine runs the full loop if Omnigent or the model is unavailable.
- Human approval gate: LYDH only produces recommendations and a record; it takes no external action. A scientist must approve any consequential step.

## Validation still needed before real-world use

1. Real observational data (e.g., real orbital or telescope data), not simulation.
2. A wider hypothesis space, including measurement error and model misspecification.
3. Independent replication by other teams.
4. Expert review of every AI-labeled hypothesis.

## Next experiment, and the path toward 10×

- Next experiment: run the same loop on public real orbital residuals, then on a domain where each experiment is expensive (materials, assays), with the planner choosing among many candidate tests under a budget.
- Toward 10×: the gain grows with problem difficulty (1.02× → 1.67× across our scenarios). In settings with many more hypotheses and costlier experiments, choosing the right test matters more. We have not measured 10× and do not claim it.

## Run it

```bash
pip install -r requirements.txt     # numpy scipy pandas matplotlib plotly streamlit
python bench.py 100                 # 4 cases x 100 repeats x 3 methods (~1 minute)
python make_backup_run.py           # saves a real run to replay in the demo
streamlit run app.py                # the app
omnigent run attn_lab/attn_lab.yaml -p "Run the discovery"   # the agent team (needs Omnigent + a model key)
```
